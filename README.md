# Симулятор уровня жидкости с ПИД-регулятором

## О программе

Приложение демонстрирует работу системы автоматического управления (АСУ) на примере регулирования уровня жидкости в резервуаре. Симулятор позволяет изучить поведение ПИД-регулятора в нормальных и аварийных режимах работы.

## Интерфейс

### Основные элементы

- **Бак с жидкостью** — визуальное отображение текущего уровня (слева)
- **График** — показывает изменение уровня во времени (справа)
- **Панель управления** — переключение режимов и настройка параметров (снизу слева)
- **Метрики качества** — отображение текущих показателей системы (снизу справа)

### Цветовая индикация

- **🟢 Зеленый** — уровень близок к заданному (ошибка < 15%)
- **🟡 Желтый** — умеренное отклонение (15-30%)
- **🔴 Красный** — сильное отклонение (> 30%)

## Режимы работы

### Ручной режим
- Пользователь самостоятельно управляет подачей жидкости через слайдер
- ПИД-регулятор отключен (коэффициенты обнулены)
- Отток жидкости изменяется случайным образом (2-4 ед.)

### Автоматический режим
- Система самостоятельно поддерживает уровень 50%
- Используются стандартные настройки ПИД-регулятора:
  - Kp = 1.6 (пропорциональный коэффициент)
  - Ki = 0.5 (интегральный коэффициент)
  - Kd = 0.3 (дифференциальный коэффициент)
- Слайдер ручного управления неактивен

### Режим настройки ПИД
- Позволяет вручную подбирать коэффициенты регулятора
- При входе в режим все коэффициенты сбрасываются в 0
- Доступны три слайдера:
  - **Kp** (0-10) — пропорциональная составляющая
  - **Ki** (0-5) — интегральная составляющая
  - **Kd** (0-5) — дифференциальная составляющая
- Позволяет экспериментировать с настройками для достижения оптимального качества

## Аварийный режим

Кнопка "Старт аварии" запускает 30-секундный тестовый сценарий:

1. Уровень жидкости мгновенно сбрасывается в критическое положение (0% или 100%)
2. Система пытается восстановить уровень до заданных 50%
3. В течение 30 секунд отслеживаются показатели качества

### Метрики качества после аварии

- **Максимальное перерегулирование** — насколько сильно уровень отклонился от уставки (50%)
- **Время стабилизации** — за сколько секунд система вернулась в зону ±3% от уставки
- **Итоговые баллы** (0-10000):
  - До 5000 баллов за перерегулирование (чем меньше, тем лучше)
  - До 5000 баллов за время стабилизации (чем быстрее, тем лучше)
  - При перерегулировании ≥50% или отсутствии стабилизации — 0 баллов

### Рейтинг системы

- **S (9000-10000)** — превосходное качество регулирования
- **A (7500-8999)** — отличное качество
- **B (6000-7499)** — хорошее качество
- **C (4000-5999)** — удовлетворительное качество
- **D (2000-3999)** — плохое качество
- **F (0-1999)** — критически плохое качество

## Текущие метрики (в реальном времени)

- **Ошибка** — текущее отклонение от уставки в процентах
- **Перерегулирование** — максимальное зафиксированное отклонение
- **Время стабилизации** — время до входа в зону ±3% (отображается "...", если система не стабилизировалась)
- **Оценка** — качественная характеристика текущего состояния

## Рекомендации по настройке ПИД

0. Рекомендовано сначала выставить входной поток **inflow** на любое непредельное значение
1. Начните с режима настройки ПИД (все коэффициенты = 0)
2. Постепенно увеличивайте Kp до появления колебаний, затем немного уменьшите
3. Добавьте Ki для устранения статической ошибки
4. При необходимости добавьте Kd для демпфирования колебаний
5. Проверьте качество настройки, запустив аварию
6. Ориентируйтесь на балльную оценку для сравнения разных конфигураций 
- (При необходимости можно сначала включить аварию и настроить коэфициенты, а уже после запустить ее заново после настройки для их проверки)

## Системные требования

- Windows 10/11
- Разрешение экрана: 1280×720 или выше
- Установка не требуется, запускается из исполняемого файла
